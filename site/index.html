Stale prices tax LPs.
This hook taxes them back.

OracleAnchoredLVRHook is a Uniswap v4 hook that prices toxic flow exactly — benign swaps pay a 5 bps base fee while informed flow trading against a stale pool pays the surcharge f* = e^{|z|/2} − 1 — and runs a permissionless on-chain Dutch auction, an open market of autonomous repricing agents, so the pool still gets repriced, with the recaptured value going to LPs. No protocol fee. Everything below reads the live USDC/WETH deployment on Base Sepolia, backed by Chainlink’s USDC/USD and ETH/USD feeds, and every EVM call this page makes is logged raw in the bus inspector.

05 the evidence chain

Backtest → contract, mechanically

A live parity suite deploys the Solidity to Anvil and asserts it returns the same fees, toxicity classifications, and width guards as the Python replay engine that produced the results. The claim-by-claim map is in design_traceability.md.

Router-grade quotability

Uniswap’s own V4Quoter prices this pool exactly — auction open or closed — with no custom integration, and it fails cleanly when the oracle is stale. See routing_integration.md.

Solver economics, measured

231k gas per fill, measured. Break-even gas prices per pool and venue scenarios in the gas-aware table — every studied pool clears with margin at Base-typical gas.

An open agent market

Repricing runs as a permissionless market of autonomous agents. The descending-concession auction coordinates competing fillers on-chain, and beforeSwap binds every fill to the LPs' policy — failing closed on non-compliant swaps — so no registry or agent attestation is needed. The whole agent interface is three public views plus an ordinary swap; a stranger poke and a stranger fill are pinned by test. See solver_bot.md.

LP uplift vs static fees

Modeled recovery ceiling of 184–264 bps of TVL/month above a static-fee baseline (Oct 2025, three majors; documented as a ceiling, not a yield, and inheriting the recapture caveat below). Observed flow: selective beats broad in 19/54 windows and ties in 35; versus static fees it is higher in 54/54, with none worse. lp_apr_uplift.md.

Honest recapture, not 99.9%

The oft-quoted “99.9% recapture” is recapture of the oracle-visible stale-loss. Measured against a faster Binance reference while the hook keeps Chainlink as its oracle, the feed lags spot by ~21 bps median, so true recapture is ~78% on mainnet feeds — higher on Base’s tighter 0.15% feed, with a faster oracle as the path to more. Every limitation is catalogued in methodology_limitations.md.
